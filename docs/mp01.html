#' Acquire Netflix What We Watched Reports
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 6, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event)
}

Description

There are 61,892 rows and 11 columns in this set.

  • year [whole number]- it is a column that shows the year a counting survey was conducted
  • period [text] - it is a column that shows the half-year a counting survey was conducted
  • period_start and period_end [calendar date] - columns that show exact dates of start and end of a counting survey was conducted respectively
  • title [text] - it is a column that shows the name of a movie (show)
  • runtime [number that can have decimals] - column that shows how long a movie (show) lasts totally
  • views [number that can have decimals] - column that shows the number of views a movie (show) got
  • hours_viewed [number that can have decimals] - column that shows total hours watched by all viewers combined
  • release_date [calendar date] - column that shows the release date of a movie (show)
  • available_globally [TRUE/FALSE (logical)] - column that shows if a movie (show) broadcasted globally
  • live_event [TRUE/FALSE (logical)] - column that shows if a movie (show) is on live broadcast

no group variables

MEMORANDUM
To: Netflix Content Strategy Leadership.
From: Business Analytics Team.
Date: October 16, 2026.
Subject: Improving Content Efficiency as Netflix’s Catalog Expands.

Intro
Nowadays Netflix is facing a problem of whether the movies (titles in out case) are producing additional viewing to ensure continuous growth. This memorandum analyses 61,892 records with detailed information alongside during half-year periods (January 2023 - June 2026). Its purpose is to identify engagement patterns and suggest ways to make content decisions more evidence-driven. Since the dataset does not include any financial information, this report is going to focus on viewing behavior not the profitability

Finding 1
The first subsequent finding that was concluded during analisys is that the number of title grew quickly, while the actual engagement of audience (viewing hours) grew much slower. For example, in the first half of 2025 Netflix reported to have 7,502 title records and 8,187 in the first half of 2026, which is an increase of approximately 9.1%. The combined runtime (viewing hours) of those listings rose 7.7%, from 58,374 to 62,855. Management is recommended to focus on prioritizing (invest in) increasing the engagement with the catalog already available rather than expanding its number.

Finding 2
Another finding is that shows take up majority of total viewing hours. Shows accounted for 64.08 billion viewing hours (90.8% of total hours), in the first half of 2025. By the first half of 2026, shows accounted 67.34 billion hours (92.5% of total hours). This increase shows that series remain central to viewing activity. For this reason, management is suggested to pay close attention. (It is als worth mentioning that for even better suggestion financial records are needed)

Finding 3
Some of the titles appeared in all 7 given time periods, for example, Breaking bad: season 1, Suits: season 1, and Money Heist: season 1. This means older and well established shows tend to keep strong engagement. It is recommended to balance promotion of new releases alongside the old one as they tend to maintain viewer’s engagement

Conclusion
Netflix is not facing a decline in total viewing hours, its number of titles is growing faster than viewing hours. A strategy focusing on engagement efficiency and sustaining catalog value would help management identify where additional content investment is most likely to have actual value.
